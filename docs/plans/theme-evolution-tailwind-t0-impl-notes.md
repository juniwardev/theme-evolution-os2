## Step 2: actual Preflight rules (node_modules/tailwindcss/preflight.css, 4.3.3)

Matches §3.2/D6 with these additions to know about:
- `html`: `line-height: 1.5`, `font-family` via `--default-font-family` (resolves to `--font-sans`, so `html` is now Work Sans instead of Times; elements under `body` already had it).
- Links: `color: inherit; text-decoration: inherit`. Headings: `font-size/weight: inherit`. Lists `list-style: none`. `table { border-collapse: collapse; text-indent: 0 }`. `[hidden]:where(:not([hidden='until-found'])) { display: none !important }`.
- `img, svg, video, canvas, audio, iframe, embed, object`: `display: block; vertical-align: middle` (the `vertical-align` is a change in 244 svg and 139 img computed values, but invisible because they are already block).
- Form controls: `font: inherit; letter-spacing: inherit; color: inherit; border-radius: 0; background-color: transparent; opacity: 1`. `*` gets `border: 0 solid; padding: 0`. `::placeholder { opacity: 1; color: color-mix(in oklab, currentcolor 50%, transparent) }`.
- Also, not in the plan: `small { font-size: 80% }`, `hr` border, `fieldset` border gone, `sub/sup`, `textarea { resize: vertical }`, `button` and `input[type=button|reset|submit]` `appearance: button`.
- `BP_md` and the `text-xs`/`text-sm` line-heights were not re-read in `theme.css` (T1 needs them; not needed for T0).

## Deviations

1. **`engines.node` is `>=22`, not `>=20.1`, and R1 says "Node 22+".** `concurrently` 10.0.6 (installed `--save-exact`, latest) requires `>= 22`; the plan said to raise it if a package needs more (R2-N7). The machine runs Node 26.
2. **`.theme-check.yml` ignore patterns are `node_modules/*`, `src/*`, `scripts/*`, not `/**`.** With `/**` the `shopify theme check` run never finished (100% CPU for minutes after `npm install`). With `/*` it runs in about 1 s.
3. `concurrently` was saved exactly (10.0.6) because the plan's install command used `--save-exact` for all three.
4. R8 sentence uses "one quoted string on one line" (R2-N4); R1 Node text per deviation 1; devops.md gets the Step 10 owner/audit file and the item-3 wording (R2-N2); Step 10's note reads "will be resolved in T1 ... T3" (R2-N1). Step 10 itself is not done (post-deploy).
5. The foundation was committed as one commit, then the ignore files, then the rules, per the plan.
